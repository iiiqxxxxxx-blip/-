# Fit Tracker Pro v6 — iPhone / GitHub Pages

Это исправленная версия для загрузки на GitHub Pages.

## Какие файлы загрузить в GitHub

Загружай в корень репозитория все файлы из этой папки:

- index.html
- manifest.json
- .nojekyll
- README.md

Важно: файл `index.html` должен лежать именно в корне репозитория, не внутри папки.

## Как включить GitHub Pages

1. Открой репозиторий на GitHub.
2. Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /root.
6. Save.

Ссылка появится примерно через 1–3 минуты:
https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

## Как открыть на iPhone

1. Открой ссылку GitHub Pages в Safari.
2. Проверь вкладки: Сегодня / Еда / Вода / Тренировки / Графики.
3. Safari → Поделиться → На экран «Домой».

## Камера и штрих-код

Камера работает только на HTTPS-сайте. GitHub Pages даёт HTTPS.
Если сканер камеры не поддерживается браузером, используй ручной ввод штрих-кода.
